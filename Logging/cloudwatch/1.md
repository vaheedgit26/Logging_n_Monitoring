# Architecture  
```text
EKS Pods
   ↓
Fluent Bit (DaemonSet via Helm)
   ↓
CloudWatch Logs (90 days retention)
   ↓
Subscription Filter
   ↓
Kinesis Firehose
   ↓
S3 Bucket (Lifecycle → IA → Glacier → Deep Archive)
```

## 1. Create IAM Role for Fluent Bit (IRSA)  
**1.1 Create IAM Policy**  
```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Action": [
        "logs:CreateLogGroup",
        "logs:CreateLogStream",
        "logs:PutLogEvents"
      ],
      "Effect": "Allow",
      "Resource": "*"
    }
  ]
}
```
**Create it:**   
```bash
aws iam create-policy \
  --policy-name FluentBitCloudWatchPolicy \
  --policy-document file://policy.json
```
**1.2 Create IAM Role (IRSA)**  
```bash
eksctl create iamserviceaccount \
  --name aws-for-fluent-bit \
  --namespace amazon-cloudwatch \
  --cluster <YOUR_CLUSTER_NAME> \
  --attach-policy-arn arn:aws:iam::<ACCOUNT_ID>:policy/FluentBitCloudWatchPolicy \
  --approve
```

## 2. Install Fluent Bit via Helm  
```bash
helm repo add aws-observability https://aws-observability.github.io/helm-charts
helm repo update
```

**2.1 Create `values.yaml`**  
```yaml
serviceAccount:
  create: false
  name: aws-for-fluent-bit

cloudWatch:
  enabled: true
  region: ap-south-1
  logGroupName: /eks/prod-logs
  logStreamPrefix: eks-
  autoCreateGroup: true

input:
  tail:
    enabled: true
    path: /var/log/containers/*.log
    parser: docker
    tag: kube.*
    memBufLimit: 50MB
    skipLongLines: On

filters:
  kubernetes:
    enabled: true
    mergeLog: true
    keepLog: false

output:
  cloudwatch:
    enabled: true
    match: kube.*
    region: ap-south-1
    log_group_name: /eks/prod-logs
    log_stream_prefix: fluentbit-
    auto_create_group: true

resources:
  requests:
    cpu: 100m
    memory: 200Mi
  limits:
    memory: 400Mi
```
**2.2 Install**  
```bash
helm upgrade --install aws-for-fluent-bit \
  aws-observability/aws-for-fluent-bit \
  -n amazon-cloudwatch \
  --create-namespace \
  -f values.yaml
```

## 3. Set CloudWatch Retention (Hot + Warm)  
```bash
aws logs put-retention-policy \
  --log-group-name "/eks/prod-logs" \
  --retention-in-days 90
```

## 4. Create S3 Bucket (Cold Storage)   
```bash
aws s3api create-bucket \
  --bucket eks-prod-logs-<ACCOUNT_ID> \
  --region ap-south-1
```

## 5. Apply Lifecycle Policy (YOUR JSON)   
Save as `lifecycle.json`**
```json
{
  "Rules": [
    {
      "ID": "log-lifecycle",
      "Status": "Enabled",
      "Transitions": [
        {
          "Days": 90,
          "StorageClass": "STANDARD_IA"
        },
        {
          "Days": 180,
          "StorageClass": "GLACIER"
        },
        {
          "Days": 365,
          "StorageClass": "DEEP_ARCHIVE"
        }
      ]
    }
  ]
}
```
**Apply:**  
aws s3api put-bucket-lifecycle-configuration \
  --bucket eks-prod-logs-<ACCOUNT_ID> \
  --lifecycle-configuration file://lifecycle.json

## 6. Create Firehose Delivery Stream   
**6.1 IAM Role for Firehose** 
```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Action": [
        "s3:PutObject",
        "s3:AbortMultipartUpload",
        "s3:GetBucketLocation"
      ],
      "Effect": "Allow",
      "Resource": [
        "arn:aws:s3:::eks-prod-logs-<ACCOUNT_ID>",
        "arn:aws:s3:::eks-prod-logs-<ACCOUNT_ID>/*"
      ]
    }
  ]
}
```

**6.2 Create Firehose**  
```bash
aws firehose create-delivery-stream \
  --delivery-stream-name eks-logs-stream \
  --delivery-stream-type DirectPut \
  --s3-destination-configuration file://firehose.json
```

**6.3 firehose.json**  
```json
{
  "RoleARN": "arn:aws:iam::<ACCOUNT_ID>:role/FirehoseRole",
  "BucketARN": "arn:aws:s3:::eks-prod-logs-<ACCOUNT_ID>",
  "Prefix": "logs/year=!{timestamp:yyyy}/month=!{timestamp:MM}/day=!{timestamp:dd}/",
  "BufferingHints": {
    "SizeInMBs": 5,
    "IntervalInSeconds": 60
  },
  "CompressionFormat": "GZIP"
}
```
**7. Connect CloudWatch → Firehose**  
```bash
aws logs put-subscription-filter \
  --log-group-name "/eks/prod-logs" \
  --filter-name "cw-to-s3" \
  --filter-pattern "" \
  --destination-arn arn:aws:firehose:ap-south-1:<ACCOUNT_ID>:deliverystream/eks-logs-stream
```

**8. Final Data Flow (Exact Behaviour)**  
```text
Fluent Bit → CloudWatch (0–90 days)

At same time:
CloudWatch → Firehose → S3

S3 Lifecycle:
0–90 days → Standard
90–180 → IA
180–365 → Glacier
365+ → Deep Archive
```

**⚠️ 9. Production MUST-DO Checklist**  
**✅ Security**  
- Enable S3 encryption:
```bash
aws s3api put-bucket-encryption ...
```
- Use KMS for:  
  - CloudWatch   
  - Firehose   
  - S3  

**✅ Reliability**
- Use Firehose buffering (already set)
- Never send directly to S3 from Fluent Bit ❌

**✅ Cost Optimisation**
- 90-day CloudWatch retention  
- Lifecycle → Glacier

**✅ Observability**
- Enable CloudWatch metrics for:
  - Fluent Bit
  - Firehose delivery failures
